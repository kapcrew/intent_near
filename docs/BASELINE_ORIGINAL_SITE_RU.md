# INTENT Property Network — актуальный архив сайта

Версия опубликованного сайта от 29 октября 2026 года.
Исходный коммит: 281d29dc4cff29e2aa0040db1f99596fbfbe720a.

## Состав
- public/ — сайт, синяя айдентика, светлая и тёмная темы, 50 объектов и карта 117 организаций.
- server/ — SKALE API, x402-оплата, policy agent и сохранение evidence.
- app/ — серверные маршруты Vinext / Cloudflare Worker.
- dist/ — готовая сборка Worker и клиентских ресурсов.
- db/, drizzle/ — структура D1 и миграции.
- tests/readiness.test.mjs — проверки условий готовности агентского исполнения.
- package-lock.json — фиксированные зависимости.
- .env.example — только имена параметров, без ключей.

Контакты: welcome@pixudi.com и https://calendly.com/pixudi.

## Быстрый просмотр интерфейса
Из папки проекта:

    python3 -m http.server 8080 --directory public

Открыть http://localhost:8080 . Это просмотр клиентской части: серверные /api требуют Worker и D1.

## Полная серверная версия
Требуется Node.js 22.13+ (рекомендуется 24), npm и Cloudflare Workers/D1.

    npm ci
    npm run build
    npm run dev

Для переноса в другое размещение привяжите D1 как DB, примените SQL-миграции из drizzle/ по порядку, настройте секреты и только после этого включайте агентские записи. Готовый Worker находится в dist/server/index.js; его конфигурация — dist/server/wrangler.json. D1 database_id в локальной сборке является заглушкой и должен соответствовать целевому размещению. Для обычного VPS потребуется окружение Worker/D1 либо отдельный серверный адаптер; одной раздачи dist/client недостаточно.

## Параметры агентского исполнения
- SKALE_AGENT_PRIVATE_KEY — ключ существующего тестового агентского кошелька, только серверный секрет.
- SKALE_ALLOWED_WALLETS — разрешённые публичные адреса операторов через запятую.
- SKALE_ENABLE_WRITE_ACTIONS=1 — включение после настройки и проверки.
- SKALE_POLICY_AGENT_ID — необязательный существующий policy agent ID.
- SKALE_X402_SELLER_ADDRESS — необязательный продавец сервиса.
- SKALE_BASE_SEPOLIA_RPC — необязательный RPC.

Ключи и секреты не входят в архив. Старые серверные данные D1 и содержимое кошельков не переносятся этим ZIP.

## Что проверено и что ещё требуется
Проверены сборка, 11 проверок готовности runtime, чтение контрактов, восемь активных settlement-листингов и поддержка SKALE Base Sepolia у PayAI. Исправлена версия домена EIP-712: имя и версия USDC теперь читаются из контракта.

Подписанная покупка Cells и полный платный агентский цикл ещё НЕ подтверждены в новом размещении: необходимы существующий серверный ключ агента, разрешённый оператор и тестовое пополнение. Валюация использует testnet reference model, а не рыночную оценку. Примерные данные объектов отмечены в интерфейсе.
